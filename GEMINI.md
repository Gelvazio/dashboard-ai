# GEMINI.md — Dashboard AI

**Única função deste arquivo:** fazer o Gemini CLI carregar o [`AGENTS.md`](AGENTS.md), a porta de
entrada das regras de **todas as IAs** (mesmo papel do `CLAUDE.md`).

- **"Salvar no `GEMINI.md`" = salvar no arquivo do assunto em `.claude/rules/`** (índice:
  [`.claude/rules/INDEX.md`](.claude/rules/INDEX.md)). Este arquivo não recebe regras.
- O `AGENTS.md` vem carregado abaixo pela importação `@./AGENTS.md`. Comandos do Gemini CLI:
  `.gemini/commands/` (gerados por `npm run sync:agentes`; não editar).
